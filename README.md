# Myriam, help me pick a perfume?

A personalized invitation for Myriam: turn a gym partnership into a little parfumerie trip, with her perfume collection and scent expertise saving the day.

## Run it

Unzip the project and open `index.html` in a browser. No installation, build process, API keys, or internet connection is needed.

To send Myriam a web link, upload the entire folder to a static website host such as GitHub Pages. Keep the HTML, CSS, JavaScript, and `assets` folder together. A path on your own computer cannot be opened on her phone.

## The flow

- “Let's pick a perfume” opens the personalized celebration page.
- “Maybe another time” shows a gentle joke and a confused perfume GIF.
- “I'll pass, thanks” closes the invitation with “See you at the gym.”
- Answers are displayed only in her browser. Nothing is recorded or sent to you; she should message you to arrange the outing.

## Files

- `index.html`: invitation and Myriam's personalized messages.
- `script.js`: yes, maybe, and decline interactions, with editable follow-up copy.
- `styles.css`: responsive shared styles and reduced-motion support.
- `yes_page.html`: perfume-shopping celebration and planning prompt.
- `yes_style.css`: celebration page styles.
- `version.json`: project metadata; no remote update check runs.
- `assets/perfume-quest.gif`: dumbbell-to-perfume side quest.
- `assets/nose-in-training.gif`: scent notes and a curious question mark.
- `assets/perfume-party.gif`: perfume bottles celebrating with confetti.
- `assets/*.png`: matching still illustrations for reduced-motion preferences.

All GIFs are original, bundled animations. They don't depend on Giphy or other external image services. The project uses system fonts and works offline.

## Customize

Edit the visible invitation in `index.html`, the yes page in `yes_page.html`, and follow-up jokes in `script.js`. Change the palette in the CSS variables at the top of `styles.css`.
